# Fraud Detection Handbook 数据适配说明

数据来自作者官方 `simulated-data-raw` 仓库的固定 commit，共 183 个每日 pickle 文件。数据由作者模拟器生成，包含金额阈值、终端临时失陷和客户凭据临时泄露三种欺诈场景。

每个客户按全局时间切为不重叠的 30 天 episode 窗口，并按天聚合为 9 维输入：交易次数、金额统计、唯一终端数及占比、交易小时的圆周均值。空白日保持全零。

`TX_FRAUD` 与 `TX_FRAUD_SCENARIO` 不进入输入。它们只用于生成窗口内首次欺诈日以及三个场景各自的首次标记日。第一版使用 Handbook 基线中常见的 7 天反馈延迟，并模拟 20% 右删失；这仍是实验构造，不是数据中的真实人工确认时间。

数据按客户分组划分，任何客户只属于 train、valid、test 中的一组。场景 1 直接由金额大于 220 产生，场景 3 会把部分交易金额乘 5，因此正式实验必须加入去金额特征消融，并分别报告三个场景的结果。
