# IBM AML HI-Small 数据适配说明

数据来自 IBM 作者发布的 `IBM Transactions for Anti Money Laundering` 数据集，采用 HI-Small 子集。数据为合成金融生态交易，完整标签由生成器给出；数据许可为 CDLA-Sharing-1.0，与代码仓库许可证不同。

主实验只使用作者声明的主要活动区间 2022-09-01 至 2022-09-10。原始文件还包含 9 月 11–18 日的 1,108 笔尾部交易，其洗钱率约 59.12%，与主要区间分布明显不同；尾部只能单独做敏感性分析，不能混入主结果。

实体定义为 `bank ID + account ID`。每个账户按日聚合流出/流入次数、金额、跨行比例、币种不匹配比例、自转账比例和流出支付方式占比，共 18 维。洗钱标签只用于定义账户首次参与洗钱交易的日期，不进入输入。

原始交易表按全部字段检查精确重复，并在生成序列前保留首条、删除后续重复记录；删除数量写入生成目录的 `manifest.json`，不以人工填写值代替实际运行统计。

模式文件包含 370 个已描述的洗钱尝试和 3,209 笔模式内交易，覆盖 FAN-IN、FAN-OUT、CYCLE、GATHER-SCATTER、SCATTER-GATHER、BIPARTITE、STACK、RANDOM 八类。并非所有洗钱交易都属于这八类，因此模式文件用于分类型评估，不替代交易表标签。
