# Method comparison

Compare full SAFEPlus with SAFE and other methods for sequential detection
under delayed labels. Use the same account splits, information available at
each prediction cutoff, outcome definitions, metrics, and model selection
budget. Fit preprocessing on training data and select model settings and
thresholds on validation data. Freeze the protocol before scoring a fresh
held-out test set.

The [audited SAFE rerun](safe_baseline/README.md) is the current exploratory
baseline. The matched comparison with full SAFEPlus and additional methods
is pending.
