任务：已知首次相关平台处置之后，回溯公开可核查的违规起点。不是未知未来处置时刻的在线预警。当前结果是已打开TEST的探索性重评分，不能称新盲测。

本协议在执行v2.1重评分前写入。复用v2的UTC、区间开闭关系、去重及读写函数；原v2程序和原评分结果保留，不重训、不改权重、不选择更有利的指标、不加权成总分。

## 固定观察范围与五种方法

窗口、事件序列、分区均读取封存Exp05文件。有效行为数N只计算真实published_revision，处置终点快照不是一次编辑。所有方法预测只能落在相同的处置前发布编辑候选位置。

1. `last_edit`：末次有效发布编辑，代表靠近平台处置的简单猜测；只作为预测对照，不更改真实标签。
2. `time_midpoint`：固定观察窗时间中点最近的有效发布编辑；距离相同取更早的位置。不用真实起点选位置。
3. `behavior`：保存的behavior_only_median。
4. `delay`：保存的delay_only_median。
5. `fusion`：保存的pred_tf_median，沿用后验中位数输出，不事后换mode或mean追分。

两条简单基线是本次事先写定的诊断对照，不是用已打开TEST选出的规则；结果仍明确是探索性。未实现新模型风险输出。

## 分流与损失

- 精确发布事件：必须由真实修订ID及UTC同时对应原事件序列，才计算event_abs=abs(khat-k)，event_norm=event_abs/(N-1)。N≤1则该标准化指标不可用，单列原因；不可见/序列外精确日志不伪造编辑位置。
- 精确UTC：time_abs=abs(that-tf)，time_norm=time_abs/(end-start)。只有固定、完整公开观察前缀与正跨度才计算标准化时间；缺失/不完整、零跨度、任意更改窗口均不得获得分数。分开报告EXACT_PUBLIC与EXACT_OTHER_LOG；所有9条混合UTC汇总仅作带说明的辅助。
- 区间：保持(L,U]。hit=L<that≤U；outside=max(L-that,0,that-U)；outside_norm=outside/(end-start)。绝不把U当精确tf。预测等于L时outside=0但hit=false，二者分别保存。配对距离比较与命中比较分开，不将它们加权或混成总分。
- RIGHT_CENSORED：保留窗口但无已知tf。当前模型无风险输出，误报率、特异度、AUC均为NOT_EVALUABLE；不得把无预测称检测正确。
- UNCERTAIN：保留候选和证据，不进入确定正负类或点误差；逐项记录不计分原因。

精确尝试时间与成功发布编辑时间分开。未能映射到发布序列的精确日志只能进入UTC及独立事件类型组，不能混进精确发布位置组。

## 汇总和配对

每个账号先除以自己的跨度/事件数，再跨账号汇总。对所有五种方法输出中位数、P90、均值、范围和有效n；P90采用线性插值：r=(n-1)*0.9，按相邻顺序统计量插值。没有数据时为null，不填0。

发布事件另外输出Exact@0和Within-1的分子、分母、比例。比率给出Wilson 95%描述区间。对fusion与四个基线逐账号分别计算赢/输/平；正比例标准化不会改变同一账号内的胜负，只会改变跨账号的汇总尺度。

配对比较分别在event_norm、time_norm、interval_outside_norm三个同质队列上报告，绝不把它们合成一个胜率。区间另列hit胜负（同命中状态打平），不把区间内更靠某个端点称为更准确。零距离的开下界可能与区间内预测在距离指标上打平，命中指标显示区别。

配对改善量=基线标准化误差-fusion标准化误差。采用固定seed20261024、2000次账号配对bootstrap，报告平均改善及95%百分位区间；若CI跨0，不宣称稳定优势。账号独立性只是描述统计假设，未知身份关联和小样本限制必须披露。

## 固定分组（只描述，不作为样本排除门槛）

- 有效编辑数：1、2–5、6–10、11–20、>20。
- 正常前缀：1、2、≥3；正常窗口不假造违规前缀。
- 区间宽度：≤1天、>1–7天、>7–30天、>30天。
- 到首次相关处置间隔：≤1天、>1–7天、>7–30天、>30天。EXACT使用td-tf；INTERVAL的真实间隔范围为[td-U,td-L)，仅当整个范围处于同一分组才分配，否则记AMBIGUOUS_RANGE。另保留最小间隔分组，明确它不是精确真实延迟。

每组仍按标签分流，保留样本量。1条正常行为、用户页、讨论页或沙盒均可成立；没有最低天数/编辑数或统一窗口要求。窗口长度与前缀数只用于解释差异。
